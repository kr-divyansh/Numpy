# NumPy — Python Numerical Computing

This repository contains my NumPy learning journey, covering fundamental concepts, array operations, mathematical computations, and numerical data manipulation using Python.

## 📌 About NumPy

**NumPy (Numerical Python)** is a powerful Python library used for numerical computing. It provides support for multidimensional arrays, mathematical functions, linear algebra, and efficient data processing.

## 🚀 Getting Started

```python
import numpy as np

# Create a NumPy array
arr = np.array([10, 20, 30, 40, 50])

# Basic operations
print("Array:", arr)
print("Mean:", np.mean(arr))
print("Maximum:", np.max(arr))
print("Minimum:", np.min(arr))
print("Sum:", np.sum(arr))
```
